# Настройка iOS Back Tap → голосовое без разблокировки телефона

## Шаг 0 — получи свой личный токен

Напиши боту `/start`, а затем `/voicetoken` — бот пришлёт личный токен вида
`a1b2c3...`. Это твой персональный ключ, не общий секрет — не публикуй его
и не давай другим людям (по нему можно писать напоминания/траты в твой аккаунт).

## Вариант B — запись через Shortcuts и отправка на backend (без открытия Telegram)

1. Открой приложение **"Быстрые команды" (Shortcuts)** на iPhone.
2. Создай новую команду:
   - Добавь действие **"Записать аудио"** (Record Audio).
   - Добавь действие **"Получить содержимое URL" (Get Contents of URL)**:
     - URL: `https://твой-домен.example/voice-webhook`
     - Метод: POST
     - Заголовки: `X-Voice-Token: <твой личный токен из /voicetoken>`
     - Тело запроса: Form (multipart)
       - Поле `audio` → файл, тип "Файл", значение = записанное аудио
3. Сохрани команду с названием, например, "Голосовое боту".
4. Настройки → Специальные возможности → Касание → **Нажатие задней панели** →
   двойное или тройное нажатие → выбери созданную команду.

Ограничение iOS: если телефон полностью заблокирован и не настроен доступ к командам
с экрана блокировки, Back Tap может не сработать — это системное поведение Apple,
обойти нельзя. В "Пункте управления" можно включить "Быстрые команды" на экране блокировки.

## Вариант A — просто открыть чат с ботом (проще, но без автозаписи)

Быстрая команда с одним действием "Открыть URL": `tg://resolve?domain=your_bot_username`.
Дальше запись голосового пользователь делает вручную зажатием микрофона в Telegram.
